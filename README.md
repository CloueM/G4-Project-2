# Alto Pharmacy Copy - School Project

This website is a group project made for our Web Development class at BCIT.

**Important Note:** This website is **not real**. It is only for school. But, the company [www.alto.com](https://www.alto.com/) is a real business. We do not own this design, and we are not trying to be the real company. We just tried to copy what the front page of [https://www.alto.com/](https://www.alto.com/) looks like so we could practice coding. None of the buttons or links work, and you cannot use this site for anything real. We respect the people who made the real site and we do not want to break any rules or laws.

## Why We Built This

The main reason for this project was to learn how to:

1. Work together as a team on code.
2. Use **SCSS**, a new tool we just learned to make websites look good.
3. Share code and work together using **GitHub**, which was a great way to learn.
